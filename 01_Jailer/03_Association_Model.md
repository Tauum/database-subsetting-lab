# Jailer association model checklist
Connect to source with PostgreSQL JDBC and read-only role. Generate a data model from schema metadata. Use subject `process_instance` and condition `id=1001` (syntax depends on UI/version). Review which outgoing/incoming associations Jailer traverses; a shared organisation may pull sibling process 1002 if reverse traversal is enabled. Add explicit associations for logical history `history.record_id -> base.id`, `external_reference.parent_process_id -> process_instance.id`, and JSONB embedded IDs only if supported by custom SQL/model rules. Do not claim JSON path links are auto-discovered. Export SQL INSERT statements and inspect dependency order and target dialect. Preserve malformed values. Exact UI labels vary by release.
