# Tonic Structural evaluation checklist
Verify current trial availability, PostgreSQL support, source connectivity, network access requirements, self-hosting rights and pricing directly with vendor before use. Do not assume a permanent free tier or local deployment rights. Use fabricated data only. Configure source and an isolated destination if required by your edition; select process 1001 and inspect relationship graph. Test stable masking of emails and names, JSONB path transformations, and malformed date preservation. Export a restorable fixture from destination with pg_dump if direct file output is unavailable. Record every extra service, storage requirement and manual intervention. Never expose the local Docker database to the public internet merely to satisfy cloud trial networking.
